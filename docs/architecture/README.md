# DTAM Framework 아키텍처 문서 세트

이 폴더는 DTAM Framework를 **소개용**, **사용자 흐름용**, **기술 구현용** 3가지 관점으로 다시 설명하기 위한 문서 세트입니다.

## 문서 구성

| 문서 | 목적 | 주요 독자 | 다이어그램 성격 |
|---|---|---|---|
| [00_intro_architecture.md](./00_intro_architecture.md) | DTAM Framework를 누구나 이해할 수 있는 최상위 구조로 소개 | 연구책임자, 외부 발표 청중, 신규 참여자 | 큰 박스 중심의 개념 아키텍처 |
| [01_user_flow.md](./01_user_flow.md) | 사용자가 DTAM으로 무엇을 하고 어떤 순서로 연결되는지 설명 | 운영자, 임무 설계자, 실험 사용자 | 양식 1 스타일 사용자 여정/스윔레인 |
| [02_technical_architecture.md](./02_technical_architecture.md) | 실제 구현된 서버, SDK, 모듈, 메시지, 데이터 저장 구조 설명 | 개발자, 통합 엔지니어, 유지보수자 | 구현 아키텍처/레이어/메시지 흐름 |

## 다이어그램 제작 원칙

1. **소개용 그림은 기술 용어를 줄이고, “무엇을 할 수 있는가”를 먼저 보여준다.**
2. **사용자 흐름 그림은 사용자의 선택과 결과를 단계별로 보여준다.**
3. **기술 구현 그림은 실제 서버/포트/모듈/ICD 메시지 경로를 명확히 보여준다.**
4. 기존 그림처럼 모든 기능을 한 화면에 넣지 말고, 목적별로 3장으로 분리한다.
